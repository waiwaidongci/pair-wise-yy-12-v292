# hxyfront-62011 马术蹄铁修整档案

源提示词编号：6

面向马术俱乐部蹄铁师的修蹄记录前端，实现「蹄铁更换 → 复查 → 冻结/恢复」的完整闭环。

## 闭环规则

1. **一蹄一条待复查**：每匹马同一蹄位（左前/右前/左后/右后）仅保留一条生效的待复查记录；再次登记即视为更换蹄铁，旧记录作废。
2. **登记必填**：步态分级（0-3 级）、左右蹄角差（度）、蹄铁类型、钉位，以及修蹄日期、下次复查日期、记录人。
3. **异常冻结**：步态三级或左右蹄角差超过 4° 时只进异常复查，不得列为可训练；复查中发现异常同样转入异常复查。
4. **复查须另一人**：复查处置的复查人必须与记录人不同，否则拒绝提交。
5. **恢复条件**：连续两次复查正常且鞋钉牢固才恢复（闭环），异常蹄位恢复前不可训练；任一复查异常或鞋钉松动都会打断连续次数。
6. **失效机制**：更换蹄铁或修订原记录（版本号 +1）会使该记录全部旧复查立即失效，连续正常次数清零。
7. **幂等提交**：复查表单凭幂等键提交，重复提交（双击/重试/刷新重提）沿用首次结果，不产生新记录。
8. **一致性**：马匹列表、复查提醒、更换历史均由同一份状态推导，并持久化到 localStorage，刷新后一致。

## 架构（规则 / 存储 / 页面分离）

```
src/
  domain/
    types.ts    # 领域类型与常量（修蹄记录、复查记录、状态）
    rules.ts    # 纯函数业务规则：判定、状态推导、登记/修订/复查流转
  storage/
    store.ts    # localStorage 读写与重置
    seed.ts     # 演示数据（经由规则函数生成，覆盖全部场景）
  pages/
    HorsesPage.tsx    # 马匹列表：四蹄闭环状态、可训练标记
    RegisterPage.tsx  # 登记修蹄 / 更换蹄铁 / 修订原记录
    ReviewsPage.tsx   # 复查提醒（逾期置顶）+ 复查处置表单
    HistoryPage.tsx   # 蹄铁更换历史与失效复查留痕
  App.tsx             # 装配层：唯一状态源 + 页签导航
```


## 规则验证

```bash
npm run verify
```

以脚本方式逐条验证闭环规则（登记必填、单蹄单记录、异常冻结、他人复查、
连续两次恢复、更换/修订失效、幂等提交、演示数据场景），共 31 项断言。
