# 马术蹄铁修整档案 · 蹄铁更换与复查冻结闭环

面向马术俱乐部蹄铁师的修蹄记录系统：建档 → 待复查 → 另一人处置 → 连续两次正常恢复，
并在更换蹄铁 / 修订原记录时立即冻结旧复查。

## 闭环规则（硬约束，集中在 `src/domain/rules.ts`）

1. **一蹄位一条待复查**：每匹马同一蹄位至多保留一条 active 复查周期。
2. **建档必填**：步态分级、左右蹄角（蹄角差）、蹄铁类型、钉位。
3. **异常冻结**：步态三级 **或** 左右蹄角差超过 4° 时，只进入异常复查，
   该蹄位（及整马）不得列为可训练。
4. **复查须另一人处置**：处置人不能与复查人为同一人；未处置的轮次不计入正常计数，
   也不能登记下一轮。
5. **恢复条件**：连续两次复查正常（步态一级、角差 ≤ 4°、鞋钉牢固）且处置齐全，
   才能确认恢复训练、关闭复查。
6. **更换蹄铁 / 修订原记录**：旧档案标记取代、旧复查立即失效（连续正常计数清零），
   按新数据重开新版本与新周期。
7. **重复提交沿用首次结果**：同一周期同一日期再次提交，不写入新数据，直接回显首次结果。

列表、提醒（逾期 / 今日 / 临近 / 待处置）、马匹可训练状态全部由同一份状态派生，
刷新页面后从 localStorage 恢复，口径一致。

## 三层结构

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 规则 | `src/domain/rules.ts` | 异常判据、正常判据、连续计数、处置人校验、提醒分级（纯函数） |
| 存储 | `src/domain/store.ts` | 状态变更、事件留痕、localStorage 持久化；只调用规则不自行解释 |
| 派生 | `src/domain/selectors.ts` | 马匹视图、复查视图、指标统计（无缓存，保证一致） |
| 页面 | `src/components/*` | 建档表单、复查工作台、马匹档案墙、历史时间线 |

## 本地运行

```bash
npm install
npm run dev          # http://localhost:62011
npm run check:rules  # 32 项闭环规则验证（不依赖浏览器）
npm run build        # 类型检查 + 生产构建
```

开发端口：62011。页面内「重置演示数据」可恢复种子数据（含逾期、异常、待处置、
待恢复、已换蹄铁失效等各种状态）。
